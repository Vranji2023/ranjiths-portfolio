# Ranjith Kumar V — Portfolio redesign

This is a React + Vite portfolio redesign in the `redesign/` directory. The original portfolio remains in the repository root and has not been overwritten.

## Run locally

```bash
cd redesign
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Netlify deployment

- Base directory: `redesign`
- Build command: `npm run build`
- Publish directory: `dist`

The demo flows are intentionally labeled frontend simulations; they do not call real AI backends. The architecture export currently downloads SVG (vector), rather than PNG. Replace/add verified live demo URLs and confirm Dr.Dine/Doctor Dyne collaboration details before public launch.
