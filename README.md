# Ranjith Kumar V — Developer Portfolio

A personal portfolio built for **Ranjith Kumar V** (Final-year B.E. CSE Cybersecurity student, Google Student Ambassador, and AI/ML builder).

Designed with a **human-first, craft-focused aesthetic** — ditching generic AI buzzwords and overused template tropes in favor of honest storytelling, real engineering problem-solving, and a Bento-style UI.

---

## 🛠️ What Was Built & Polished:

1. **Human & Authentic Storytelling**:
   - Written in Ranjith's genuine first-person voice.
   - Explains *why* Cybersecurity and AI intersect (adversarial prompts, securing LLM pipelines, prompt hallucination defense).
   - Real stories behind **LandCase AI** (HACKASTORM 2.0 hackathon finalist) and **Dr.Dine** (from Flask rule-engine to OCR + Logistic Regression in Streamlit).

   - **One-Click Copy Email** button with an instant toast notification.
   - **Dark / Light Theme** toggle with local storage persistence.

3. **Complete Resume Integration**:
   - Clean embedded resume modal with 1-click **Print / Save as PDF** option.
   - Verified credentials from **Microsoft Security Copilot**, **Anthropic**, **Deloitte**, **LinkedIn Learning**, **Outskill**, and **Google**.

4. **Interactive Deep-Dive Modals**:
   - Technical breakdowns of system prompt design, anti-hallucination guards, and Tesseract OCR preprocessing.

## ⚡ How to Run Locally

1. **Double-click `index.html`** to view it directly in any browser.
2. Or run Python's local server:
   ```powershell
   python -m http.server 3000
   ```
   and navigate to `http://localhost:3000`.
